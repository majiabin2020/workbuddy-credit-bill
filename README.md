# 任务X光（task-xray）

一个能让你看清「积分到底花在哪了」的 WorkBuddy 小工具。装上以后，你对 AI 说一句话，它就会把你最近每个任务的完整过程摆出来给你看：什么时候在思考、读了哪些文件、调了哪些工具和技能，以及每一步具体烧了多少 token、多少积分。

## 你是不是也遇到过这种事

经常有粉丝问我：老马，我看 GLM-5.3-Flash 的倍率是 0.06x，DeepSeek-4.1-Flash 是 0.11x，明明前者更便宜，为什么我用下来前者反而更耗积分？一个问题几十上百积分，后者一般就十几二十几，这不对劲啊。

我一开始也觉得奇怪，后来把自己电脑上几个月的账翻出来算了一遍，才发现问题出在哪。积分这件事，倍率只决定「每单位 token 多少钱」，而真正决定你账单的，是这一个任务里 agent 实际烧掉了多少 token。你想啊，agent 每思考一轮、每读一次文件、每调用一次工具，返回来的内容都会塞进上下文里，然后跟着下一轮请求原样再发一遍。任务越复杂，轮次越多，上下文就像滚雪球一样越滚越大。所以同样一个任务，在 A 模型那边跑了五十轮，在 B 模型那边只跑了八轮，就算 A 的倍率更低，最后账单也照样更贵。这不是倍率标错了，是任务本身的差别。

这个工具就是为把这个过程讲清楚而做的。它的思路来自 DeepSeek Harness 上一个叫 dsh-context 的插件，我在微信公众号看到开源君介绍这篇文章，觉得这个思路特别对，就照着给 WorkBuddy 做了一个。

## 装上之后能看到什么

打开看板，最上面是总账：多少个会话、多少步请求、一共花了多少积分、其中思考占了多少、缓存命中率是多少。下面紧跟着一段用你自己账单算出来的解释，告诉你本机花钱最多的是哪个模型、它标称倍率多少、实际每百万 token 又要多少积分，两个数放一起，你立马就明白倍率和账单不是一回事。

再往下是模型对比，每个模型的步骤数、token 构成、累计积分、实际积分率都列得清清楚楚。然后是会话列表，你最近做过的每个任务都在这，按时间排得整整齐齐。你点任意一个任务，它就把这个任务的完整过程回放给你看：你问的是什么，agent 先想了什么，然后调了什么工具，工具返回了什么，接着又想，一步步到最后交差。每一步右边都带一个小色条，标出这一步的输入、缓存命中、思考、输出各占多少，以及这一步花了多少积分。回放最上面还有一张「上下文滚雪球」图，哪几步请求的输入突然变大，一眼就能看出来，token 就是在那几步涨起来的。

思考的原文和工具调用的参数默认是收着的，点一下才展开，这样你截图发给别人的时候也不用担心泄露太多东西。

## 怎么安装

安装很简单，整个文件夹拷进去就行了，不用装任何别的东西。你先到 GitHub 上把这个仓库下载下来（地址是 github.com/majiabin2020/workbuddy-task-xray，进去之后点 Code，再点 Download ZIP 就可以），下载完解压，里面有一个叫 task-xray 的文件夹，你把这个文件夹整个复制到 WorkBuddy 的技能目录里就行。Mac 上这个目录是「你的用户文件夹/.workbuddy/skills/」，Windows 上一般是「C:\Users\你的用户名\.workbuddy\skills\」。放好之后把 WorkBuddy 彻底关掉再重新打开，新技能就装好了。

这里提醒一句，.workbuddy 这个文件夹默认是隐藏的，Mac 上你可以在访达里按 Command+Shift+. 把它显示出来，Windows 上在文件资源管理器的查看选项里勾上「显示隐藏的项目」就能看到了。如果你嫌麻烦，也可以直接让 AI 帮你装，你把这个仓库链接发给它，让它把 task-xray 文件夹放到技能目录里，它顺手就办了。

## 装好之后怎么说

装好以后，你直接在对话里跟 AI 说「看看我的积分花在哪」，或者说「生成任务X光看板」，它就会帮你跑一遍，然后把看板打出来给你。第一次用的时候，它还会问你要不要建一个固定入口，建议是要，这样以后每天上午九点它都会自动帮你刷新一份最新的，你在左边菜单的资料库里点开就能看，不用每次重新说。

## 大家可能想问的

有粉丝问我，我按你说的说了，但是 AI 说找不到日志，这是怎么回事？这种情况一般是你这台电脑上还没怎么用过 WorkBuddy，或者日志放在别的目录里，你跟 AI 说明一下实际情况，它自己有参数可以指定目录。

还有人说，我以前的会话更重要，能看到更早的吗？可以。默认看板会嵌入最近三十天的完整回放，更早的任务只显示汇总。你想看成更早的，就跟 AI 说一句「用九十天的窗口重新生成」，或者说「全部历史都要」，它就会按你说的重新跑一遍。

也有人担心，这些数据会不会传到别人那里去。这个你放心，看板全部是在你自己电脑上算的，读的是本机日志，生成的是一个本地网页文件，除了抓一下官方模型倍率页面，全程不联网也能用，你的对话内容一个字节都不会出去。

## 老马的话

工具做出来是给人用明白的。积分这件事从来不是「哪个模型便宜」这么简单，它取决于你让 agent 干了什么、干得多深。看清了过程，你自然就知道下一回怎么省。这个工具开源出来，欢迎大家拿去用，也欢迎去 GitHub 上点个星。WorkBuddy 的玩法还有很多，我会持续在公众号和 B 站（搜「马佳彬V」）分享，有问题也欢迎在评论区找我。
